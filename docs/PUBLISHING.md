# Публикация и обновление репозитория

31 октября 2026 года по запросу пользователя создан приватный репозиторий [MrHammerWin/crmn-agent](https://github.com/MrHammerWin/crmn-agent). Начальный код, документация и сохранённые результаты загружены в ветку `main`. У папки `crmn-agent` собственный Git репозиторий; остальные файлы родительской папки МИФИ в него не входят.

При дальнейших обновлениях:

1. Сохранять приватную видимость, пока пользователь не попросит её изменить.
2. Проверить `git status` и список добавляемых файлов. Репозиторий должен содержать только эту папку проекта, а не все учебные и личные документы из родительской папки МИФИ.
3. Не добавлять `.venv`, `.env`, ключи, папки `models`, `data`, `external` и приватные журналы.
4. Оставить ссылки на CRMN, бенчмарки, модель и заимствованные методы. Реальные результаты не заменять выдуманными или взятыми из чужого leaderboard.
5. Согласовать лицензию на собственный код перед добавлением файла LICENSE. Существующие лицензии внешних пакетов сохраняются.
6. Включить фактически проведённые тесты и статус незавершённых сравнений в README.

Обычное обновление из папки проекта: проверить `git status`, добавить выбранные изменения, создать коммит и выполнить `git push origin main`. В GitHub Actions настроены установка зависимостей, подготовка ALFWorld, Ruff и pytest; вызовы LLM в этом workflow не выполняются.

`requirements-lock.txt` фиксирует локальное проверенное окружение Apple Silicon. Перенос на Linux требует исключить MLX/Metal или выбрать OpenAI backend. Изменение платформы — новый эксперимент с собственной записью версий.
