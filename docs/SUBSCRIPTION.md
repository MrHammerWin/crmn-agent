# Доступ по подписке ChatGPT

На этом компьютере проверен вход Codex CLI через ChatGPT. Пользователь разрешил до 30 отдельных запусков CLI для технических игровых экспериментов. Это не API ключ и не API оплата.

Пробные GPT 6 Luna и GPT 6.1 Sol были отклонены установленным CLI. GPT 5.6 Luna из фактического списка моделей успешно вернула ответ с учётом токенов. Не следует переносить ограничения установленного CLI на общую доступность этих моделей в OpenAI API.

`CodexProvider`:

- использует `--ignore-user-config`, пустую папку контекста, `project_doc_max_bytes=0` и ephemeral сеанс;
- отключает shell tool, apps и web search и задаёт пустой набор MCP серверов;
- передаёт только текст игрового контекста и схему ответа;
- отвергает результат, если JSON журнал показывает выполнение команд, MCP вызовов, поиска или изменения файлов;
- исключает API ключи из окружения дочернего процесса и проверяет ChatGPT sign-in;
- учитывает все попытки в общем, блокируемом `fcntl` реестре `local/subscription_budget.json`;
- не печатает исходный stderr, который мог бы содержать чувствительные сведения.

Количество `calls` для этого backend означает число запусков CLI, не точное число внутренних HTTP запросов Codex. Реальные токены берутся из `turn.completed`. Они включают служебный контекст CLI, поэтому их нельзя напрямую смешивать с расходами чистого OpenAI API. Жёсткое ограничение — количество запусков; финальный токеновый расход становится известен после ответа. Параметр `max_output_tokens` общего интерфейса не является гарантированным ограничением вывода CLI.

`configs/subscription_probe.json` — техническая проверка на трёх средах, с 1 действием в ALFWorld/TextCraft и 2 действиями в BabyAI goto. Это не стандартный протокол бенчмарка и не оценка SOTA успешности. Остальные четыре типа BabyAI проверялись в локальной серии.

Документация: https://learn.chatgpt.com/docs/non-interactive-mode ; https://learn.chatgpt.com/docs/auth .
