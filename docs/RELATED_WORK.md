# Источники и близкие работы

## Источник механизма

1. Kawato M., Cortese A. **From internal models toward metacognitive AI**. Biological Cybernetics, 2021. https://doi.org/10.1007/s00422-021-00904-7
2. Cortese A., Kawato M. **The cognitive reality monitoring network and theories of consciousness**. Neuroscience Research, 2024. https://doi.org/10.1016/j.neures.2024.01.007

Пары генеративных и обратных моделей, ответственность по ошибкам и выбор модулей заимствованы из этих работ. Они не заявляются оригинальным изобретением автора курсовой. Поиск не установил отсутствие всех возможных аналогов. Наличие новой реализации и перенос на текстовые LLM задачи сами по себе не доказывают принципиальную новизну механизма.

## Реализованные базовые сравнения

- **ReAct**: Yao et al., 2023. https://arxiv.org/abs/2210.03629 — последовательность краткого рассуждения и действия. В проекте — собственная zero-shot prompt реализация с общей структурой выхода, а не опубликованный few-shot leaderboard запуск.
- **ReflAct**: 2025. https://aclanthology.org/2025.emnlp-main.1697/ — отражение текущего состояния и разрыва до цели. В проекте — собственная prompt реализация этой стратегии. Шаблон краткий и не объявляется точной копией всех настроек статьи.

Эти методы дают содержательные контроли, но ни возраст статьи, ни слово agent не делают их двумя актуальными SOTA по выбранному бенчмарку.

## Запланированные сильные конкуренты

- **MAP**, 2026. https://arxiv.org/abs/2605.13037 — предварительное изучение среды, построение карты и выполнение с её использованием. В проверенном тексте нет найденной ссылки на официальный исполнимый репозиторий. Изложение метода не заменяет точное воспроизведение. Переобучение и глобальная фаза исследования должны учитываться в протоколе.
- **ALMA**, 2026. https://arxiv.org/abs/2602.07755 ; https://github.com/zksha/alma — метаобучение исполнимых дизайнов памяти. Авторы предоставляют код с контейнерными средами и отдельным процессом поиска. Ручная память эпизодов не является воспроизведением ALMA. Для TextCraft и BabyAI нужны новые адаптеры и согласование режимов накопления памяти.
