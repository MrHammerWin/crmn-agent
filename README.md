# Метакогнитивный контроль LLM агента на основе CRMN

Локальный исследовательский проект для курсовой: агент выбирает между картой фактов и планом подцелей, оценивая сохранность наблюдаемой информации и ошибки предсказаний. Теоретическая основа — CRMN Kawato и Cortese. Это инженерная адаптация, а не изобретение принципа CRMN и не модель сознания.

## Что реализовано

- Два модуля представления и независимое обратное восстановление фактов. Декодер не получает исходные наблюдения и историю.
- Выбор модуля по ошибкам восстановления, наблюдаемым последствиям действий и ожидаемой полезности. Неизвестный результат не считается ошибкой.
- Обучаемый небольшой prior выбора модулей; обучение разрешено только на train. По умолчанию prior равномерный и не обучен.
- Бейзлайны `react`, `reflact`, `naive`; абляции `no_cycle`, `no_prediction`, `no_reward`, `map_only`, `plan_only`.
- Адаптеры ALFWorld, TextCraft и пяти типов BabyAI-Text из BALROG.
- Общие ограничения вызовов, токенов и денег, сохранение траекторий, проверка возобновления, парные сравнения и доверительные интервалы.

**Статус экспериментов:** см. [STATUS.md](STATUS.md). Технические проверки и короткие запуски небольшой локальной модели не доказывают превосходство над SOTA. MAP и ALMA не подменены простыми промптами; их полное воспроизведение остаётся отдельным пунктом работы. Статья сейчас не создаётся по просьбе пользователя.

## Быстрый запуск на этом компьютере

Откройте терминал в этой папке. Подготовленное окружение находится в `.venv`.

```bash
PYTHONHASHSEED=0 .venv/bin/python -m pytest -q
PYTHONHASHSEED=0 .venv/bin/crmn doctor --config configs/local_pilot.json
PYTHONHASHSEED=0 .venv/bin/crmn evaluate --config configs/local_demo.json
```

Для повторного запуска задайте новую папку `results_dir` в копии конфигурации. `--resume` продолжает только тот же эксперимент с неизменными исходниками и параметрами. Уже выполненные эпизоды не дублируются.

```bash
.venv/bin/crmn analyze results/local_pilot/episodes.jsonl
```

На Mac локальной модели нужен доступ к Metal GPU. В ограниченной песочнице Codex он может быть недоступен; обычный терминал macOS запускает тот же код без этой изоляции. Для локальной структурированной генерации используется Outlines. Генераторы схем кэшируются, а ограничения длины строк проверяются Pydantic после генерации, чтобы избежать слишком больших конечных автоматов.

## Установка заново

Python 3.11 или новее. На этом Mac проверяется Python 3.12. MLX используется только на Apple Silicon.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/python scripts/prepare_alfworld.py
.venv/bin/python scripts/download_model.py
```

Последняя команда скачивает **только** заранее выбранную открытую Qwen2.5 1.5B в формате 4 bit и проверяет предел 2 ГБ до скачивания. Модель не загружается автоматически при запуске эксперимента. Папки `models`, `data` и `.venv` исключены из Git.

## Подключение OpenAI позже

Подписка ChatGPT не является обычным API-ключом. API-вызовы отключены. Реальные ключи не сохраняются в коде, конфигурации эксперимента и Git.

На этом компьютере также проверен отдельный backend `codex`, использующий вход по подписке. Его пользовательский лимит в 30 запусков уже израсходован. Он не обнуляется при рестарте. Подробности и ограничения сопоставимости расходов — в [SUBSCRIPTION.md](docs/SUBSCRIPTION.md). Обычный локальный пример использует MLX и не расходует этот лимит.

1. Настроить `OPENAI_API_KEY` локально, не передавая значение в чат или репозиторий.
2. Создать копию `configs/openai_pilot.json`.
3. После отдельного разрешения владельца задать `allow_paid: true` и положительный `max_usd`.
4. Проверить актуальные цены выбранной модели и вписать ставки токенов в конфигурацию.
5. Запустить `crmn evaluate --config <копия конфигурации>`.

Если бюджет равен нулю, программа останавливается **до первого сетевого API-запроса**. Автоматические SDK retries отключены; каждый вызов учитывается. Таймаут API консервативно учитывается как потенциально оплаченный запрос. Кэшированные ответы не выдаются за новые независимые повторы.

## Где лежат результаты

В папке конкретного запуска:

- `run.json` — конфигурация, версии пакетов, хеш исходников, время и общий расход;
- `episodes.jsonl` — отдельные эпизоды, успех, действия, наблюдения, ошибки и диагностика контроллера;
- `model_calls.jsonl` — реальные ответы модели и накопленный расход, без API-ключей;
- `summary.csv` — сводные показатели и интервалы успешности;
- `paired_comparisons.json` — разности успешности на совпадающих задачах и seed.
