# Работа с проектом

Это локальная реализация курсовой. Пользователь пока запретил платные API вызовы и попросил не писать статью. Эти ограничения действуют до нового явного указания пользователя. GitHub репозиторий пока не создаётся.

Пользователь отдельно разрешил до 30 запусков Codex CLI по подписке ChatGPT. Общий счётчик — `local/subscription_budget.json`. Он включает неудачные попытки выбора модели. Не обнулять счётчик и не создавать обходной реестр для продолжения без нового разрешения. Выбранная доступная модель — GPT 5.6 Luna; более новые имена не поддерживаются установленным CLI.

Использовать `.venv/bin/python`; перед проверками задавать `PYTHONHASHSEED=0`. Основные проверки: `python -m pytest -q` и `ruff check src scripts tests`. Для MLX требуется Apple Silicon с доступом к Metal.

Не смешивать технические тесты, синтетические диагностики и реальные прогоны LLM. Не выдавать ReAct/ReflAct prompt реализации за два воспроизведённых современных SOTA. Сохранять CRMN Kawato и Cortese как источник механизма. Не заявлять превосходство, пока оно не подтверждено сопоставимым экспериментом.

Тестовые задания нельзя использовать для обучения prior или подбора параметров. При изменении исходников или конфигурации создавать новый results_dir. Сохранять неудачные запуски, не заменять их выдуманными результатами. Не публиковать `.env`, модели, наборы заданий и локальное окружение.
